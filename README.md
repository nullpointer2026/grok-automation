# Grok Automation

Grok Automation 是一个用于 `grok.com` 的浏览器扩展，可以在 Grok 页面中批量提交提示词，并自动检测新生成的视频资源，将视频下载到本地“下载”目录中的指定文件夹。

## 功能

- 批量提交提示词，提示词之间使用空行分隔
- 支持从 `.txt` 文件导入提示词
- 支持设置并发任务数和随机延迟
- 自动检测 Grok 页面中新生成的视频
- 自动下载视频到指定文件夹
- 支持导出运行日志和失败提示词
- 提供连接测试，方便检查扩展是否能识别 Grok 输入框和发送按钮

## 安装

### Chrome / Edge

1. 打开浏览器扩展管理页：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹 `GrokAutomation`。
5. 打开 `https://grok.com/`，点击浏览器工具栏中的 Grok Automation 图标打开侧边栏。

## 使用方法

1. 先登录并打开 Grok 页面，建议进入图片/视频生成相关页面。
2. 在扩展侧边栏的“控制”页输入提示词。
3. 多条提示词之间使用空行分隔，也可以上传 `.txt` 文件导入。
4. 设置并发数、随机延迟和保存文件夹。
5. 点击“测试连接”，确认扩展能找到输入框和发送按钮。
6. 点击“开始运行”。
7. 生成完成后，视频会自动保存到浏览器默认下载目录下的指定文件夹。

## 文件说明

- `manifest.json`: 浏览器扩展清单文件
- `background.js`: 后台脚本，负责侧边栏通信和下载任务
- `content.js`: 注入到 Grok 页面中的脚本，负责输入提示词、点击发送、检测视频
- `sidepanel.html`: 扩展侧边栏页面
- `sidepanel.js`: 侧边栏交互逻辑、队列处理和日志导出
- `sidepanel.css`: 侧边栏样式
- `icons/`: 扩展图标

## 权限说明

本扩展会请求以下权限：

- `storage`: 保存扩展设置
- `downloads`: 下载生成的视频和日志文件
- `sidePanel`: 显示浏览器侧边栏界面
- `scripting`: 在 Grok 标签页中注入内容脚本
- `activeTab` / `tabs`: 查找并与已打开的 Grok 页面通信
- `https://grok.com/*`: 仅在 Grok 页面中运行内容脚本

## 注意事项

- 并发数建议设置为 1 到 3，过高可能触发 Grok 限流。
- 当前核心自动化流程主要面向视频生成和 `.mp4` 下载。
- 如果 Grok 页面结构更新，扩展可能需要同步调整输入框、发送按钮或视频检测逻辑。
- 下载位置受浏览器默认下载目录影响，扩展设置的文件夹会创建在默认下载目录下。
